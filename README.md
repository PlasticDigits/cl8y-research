# cl8y-research

Rust + Postgres worker for CL8Y ecosystem research: weekly blog drafts
and vector search over allowlisted primary sources.

This repo exists so `CL8Y-web` can stay a static Vite SPA. Secrets,
Telegram sessions, indexer tokens, and Replicate spend live here, not
in the marketing site.

See the upcoming worker implementation (GitLab issue moved from
[`CL8Y-web#4`](https://gitlab.com/PlasticDigits/CL8Y-web/-/issues/4)).
